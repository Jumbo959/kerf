# kerf

Раскладка деталей на листе, если пила ходит насквозь. На вход лист, ширина пропила, обрезь с краёв и детали. На выход координаты, линии реза и процент использования.

Миллиметры, только целые. `along` оставляет деталь как записана. `across` поворачивает на 90. `none` выбирает поворот, после которого остаётся более крупный кусок.

Деталь, которая больше чистого поля, попадает в `left`. Лист под неё не открывается.

Кухня из `examples/kitchen.json`, лист 2800×2070, пропил 4 мм, кромка 10 мм:

```
sheets 1
yield 53.1%
used 3077472
left none
```

На один шкаф целый лист не уходит, остаток виден на `examples/kitchen.svg`.

```
npm test
node dist/cli.js examples/kitchen.json
```

Рез только гильотинный: внутри уже отрезанного прямоугольника, от края до края. Кривые детали и припуск на кромку ПВХ сюда не входят.
